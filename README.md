# **Dormitory Repair System**
ระบบแจ้งซ่อมหอใน คือ ระบบ Web Service ที่พัฒนาในรูปแบบ RESTful API เพื่อให้นักศึกษาหอในสามารถแจ้งปัญหาการชำรุดภายในห้องพักหรือพื้นที่ส่วนกลาง เช่น ไฟเสีย น้ำรั่ว แอร์ไม่เย็น ผ่านเว็บไซต์หรือแอปพลิเคชัน และเจ้าหน้าที่สามารถเข้ามาจัดการงานซ่อมและอัปเดตสถานะได้
ฟีเจอร์หลักของระบบ ได้แก่

---
## **Authentication API**

1. สำหรับเข้าสู่ระบบ:
POST /api/auth/login
2. ดึงข้อมูลของผู้ใช้ที่กำลัง login:
GET /api/auth/me

**Responsible:** 
**ณัฏฐ์ เพิ่มกิตติกุล 6609650335**

---
## **Maintenance Request API**

POST /api/requests
2. ดูรายการแจ้งซ่อมของตัวเอง:
GET /api/requests/my

**Responsible:** 
**พรธีรา เสาวรส 6609650517**

GET /api/requests/{id}

# **สิ่งที่จำเป็นต้องมีก่อนการติดตั้ง (System Prerequisites)**

เพื่อให้แอปพลิเคชันหลังบ้านสามารถประมวลผลและทำงานได้อย่างถูกต้อง ไคลเอนต์และเครื่องผู้ทดสอบระบบจำเป็นต้องมีสภาพแวดล้อมดังต่อไปนี้:
Node.js Environment: เวอร์ชันมาตรฐานเสถียร (LTS v16.x หรือสูงกว่า) เพื่อรองรับฟีเจอร์ JavaScript ES6+
Node Package Manager (npm): เวอร์ชัน 8.x ขึ้นไปสำหรับจัดการคลังคำสั่งโมดูลภายนอก
API Testing Tool: โปรแกรม Postman หรืออินเทอร์เฟซตัวทดสอบระบบอื่น ๆ เพื่อใช้ส่งคำร้องจำลอง HTTP Request

## **ขั้นตอนการติดตั้งระบบอย่างละเอียด (Step-by-Step Installation Guide)**
กรุณาดำเนินการตามลำดับขั้นตอนด้านล่างนี้ใน Terminal หรือ Command Prompt เพื่อติดตั้งระบบ:

### **ขั้นตอนที่ 1: การเข้าสู่ไดเรกทอรีโครงการ**
เปิดโปรแกรม Terminal บนเครื่องคอมพิวเตอร์ของคุณ จากนั้นย้ายโฟลเดอร์ทำงานปัจจุบันเข้าไปยังตำแหน่งไดเรกทอรีหลักของโปรเจกต์แจ้งซ่อมหอพัก:
```bash

cd CS367_Dormitory-Repair-System
```
### **ขั้นตอนที่ 2: การติดตั้ง Dependencies และสภาพแวดล้อมทำงาน**
ทำการสั่งการระบบ npm เพื่อตรวจสอบโครงสร้างไฟล์ package.json และทำการดาวน์โหลดชุดซอร์สโค้ดเครื่องมือช่วยพัฒนา, คลังมิดเดิลแวร์หลัก และตัวทดสอบระบบ (jest, supertest) ลงมาฝังไว้ในโฟลเดอร์ node_modules ภายในเครื่อง:
```bash
npm install
```
### **ขั้นตอนที่ 3: การเปิดสถานีเซิร์ฟเวอร์หลัก (Server Launch)**
ทำการรันสคริปต์หลักของระบบเพื่อปลุกสถานีหลังบ้าน (Express Server) ขึ้นมาสแตนด์บายคอยรับฟังคำร้องจากฝั่ง Client ตลอด 24 ชั่วโมง โดยพิมพ์คำสั่ง:
```bash
npm start
```
**หากการตั้งค่าและพอร์ตทำงานว่างอยู่ หน้าจอ Terminal จะแสดงข้อความค้างไว้ว่า:
```bash
SERVER.JS RUNNING
Server is running on port 3000
```
