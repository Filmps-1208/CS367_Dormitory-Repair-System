# **Dormitory Repair System**
ระบบแจ้งซ่อมหอใน คือ ระบบ Web Service ที่พัฒนาในรูปแบบ RESTful API เพื่อให้นักศึกษาหอในสามารถแจ้งปัญหาการชำรุดภายในห้องพักหรือพื้นที่ส่วนกลาง เช่น ไฟเสีย น้ำรั่ว แอร์ไม่เย็น ผ่านเว็บไซต์หรือแอปพลิเคชัน และเจ้าหน้าที่สามารถเข้ามาจัดการงานซ่อมและอัปเดตสถานะได้
ฟีเจอร์หลักของระบบ ได้แก่

---
## **Authentication API**

1. สำหรับเข้าสู่ระบบ:
POST /api/auth/login
2. ดึงข้อมูลของผู้ใช้ที่กำลัง login:
GET /api/auth/me

**Responsible:** 
**ณัฏฐ์ เพิ่มกิตติกุล 6609650335**

---
## **Maintenance Request API**

1. สร้างคำร้องแจ้งซ่อม:
POST /api/requests
2. ดูรายการแจ้งซ่อมของตัวเอง:
GET /api/requests/my

**Responsible:** 
**พรธีรา เสาวรส 6609650517**

4. ดูรายละเอียดงานซ่อมแต่ละรายการ:
GET /api/requests/{id}
ใช้
5. สำหรับเจ้าหน้าที่รับงาน:
PUT /api/requests/{id}/assign

**Responsible:** 
**ภูริต เฟื่องฟู 6609650038**

7. เปลี่ยนสถานะ:
PUT /api/requests/{id}/status
8. สำหรับนักศึกษายกเลิกคำร้อง:
DELETE /api/requests/{id}

**Responsible:** 
**กชมนต์ บริบูรณ์ 6609650145**

## **File Upload API**
1. แนบรูปภาพประกอบการแจ้งซ่อม:
POST /api/requests/{id}/upload

**Responsible:** 
**อาภาวรรณ กงกะนันทน์ 6609650020**

## **Report API**
1. สำหรับผู้ดูแลระบบ เพื่อดูสถิติการแจ้งซ่อมในแต่ละเดือน:
GET /api/reports/monthly

**อาภาวรรณ กงกะนันทน์ 6609650020**
